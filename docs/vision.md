# 看屏幕与看图片

后台 Agent 可以看用户当前的屏幕，或看一张已有的图片，用来回答「屏幕上这个报错是
什么意思」这类问题。

配置项见[配置说明](configuration.md#看屏幕与看图片)。

## 使用

开启后正常说话即可：

```
看看我屏幕上现在显示什么
帮我看下屏幕上这个报错是什么意思
看一下 /tmp/shot.png 这张图片，告诉我里面是什么
```

不指定路径时截取当前屏幕，指定路径时读取该文件。支持 `.png`、`.jpg`、`.jpeg`、
`.gif`、`.webp`，单张 8MB 以内。

截屏目前仅支持 macOS，并需要「屏幕录制」权限。该权限归属父进程，因此要授权给运行
Gateway 的终端或桌面应用，并重启该应用后生效。指定已有图片的路径不需要此权限。

## 为什么这项能力在后台

Realtime 前台的 session 只声明文字和音频两种模态，无法接收图像。同时前台的工具集
是固定的七个，[架构文档](architecture.md)明确列出了它不应具备的能力。所以看图不能
由前台完成，也不应为它新增前台工具。

请求因此走普通的后台委派：前台用已有的委派工具把请求交给后台，后台 Agent 自行判断
是否需要看，再调用 Gateway 注入的看图工具。识别在协调层完成，不需要开启第三层项目
Session。

## 两种交付方式

图像如何到达模型，取决于是否配置了独立的视觉模型。

**图像直接交给后台 Agent**（不设 `QWEN_AUDIO_AGENT_VISION_MODEL`）

图像作为 ACP prompt 的 image content block 发送，并以 Agent 在握手时声明的
`promptCapabilities.image` 为门禁。声明不支持时不发送图像，转而让 Agent 告知用户，
而不是猜测图中内容。

Agent 拿到的是原图，可以反复审视细节，也能基于看到的内容继续操作。代价是整个 Agent
都运行在视觉模型上，包括与图像无关的工作。

**由独立视觉模型描述后交给 Agent**（设置 `QWEN_AUDIO_AGENT_VISION_MODEL`）

Gateway 调用该模型，把文字描述交给 Agent，后台因此可以使用纯文本模型。

这不只是一种优化选择。ACP 协议没有模型概念，也没有在 Session 内切换模型的方法，
Session 的模型在 Agent 启动时即固定。所以「Agent 使用文本模型但仍能看图」只能由
Gateway 另行调用一个模型来实现。

这也决定了后端的兼容范围。部分 ACP 适配器使用 `/v1/responses` 作为传输协议，而多数
服务商的多模态模型只在 `chat/completions` 上提供，两者在第一种方式下没有交集。第二
种方式让 Agent 与视觉模型各自使用适合的端点，因此所有后端都能看图，无论其自身模型
是否具备视觉能力。

**如何选择**

| | 图像交给 Agent | 独立视觉模型 |
| --- | --- | --- |
| 后台模型要求 | 必须具备视觉能力 | 任意 |
| Agent 收到 | 原图 | 文字描述 |
| 能否反复审视细节 | 能 | 不能 |
| 后端兼容范围 | 取决于其传输协议 | 全部 |

需要 Agent 对着图像反复推敲时选第一种，其余情况建议第二种：它对后端与模型的要求更
宽松，且后台模型的上下文中不必承载图像数据。

## 权限与隐私

看图工具不属于 Gateway 自动放行的工具集合，因此 Gateway 不会静默批准一次看屏幕。
屏幕上可能有密码、私信或财务信息，一次同意不代表下一次同意。

实际是否向用户弹出确认，还取决于后端自身的沙箱策略——部分后端不把截屏视为需要确认
的操作。

图片保存在配置目录的 `screenshots/` 下，权限 `0600`，目前不会自动清理。指定已有图片
时会先复制再处理，不会修改原文件。

## 实现要点

| 文件 | 作用 |
| --- | --- |
| `server/src/agent/screen-capture.mjs` | 截屏、读取图片文件、缩放 |
| `server/src/agent/vision-describer.mjs` | 调用独立视觉模型取得描述 |
| `server/src/agent/acp-session-tools.mjs` | 注册看图工具 |
| `server/src/agent/acp-process-client.mjs` | prompt image content block 与能力门禁 |
| `server/src/agent/agent-client.mjs` | 按开关与平台装配 |

几处取舍：

- **不引入新依赖。** 截屏与缩放使用 macOS 自带的 `screencapture` 与 `sips`
- **截屏静音。** 语音产品中，快门声会被麦克风收录进对话
- **图像必须缩放**，默认长边 1568。一张高分屏截图有数百万像素，不缩放会让模型上下文
  的很大部分消耗在无法利用的像素上
- **读取已有图片时先复制再处理。** 缩放是原地改写，修改用户自己的文件不该是「问一句」
  的副作用
- **调用系统命令一律使用 argv 数组而非 shell 字符串**，且路径先转为绝对路径，避免
  注入与参数歧义
- **默认关闭。** 未开启时看图工具不会注册，后台看不到这项能力

## 已知限制

用户目前无法直接上传或粘贴图片：可以让后台截屏，或在对话中说出一个已有图片的路径。
界面侧的图片输入尚未实现。
