# 资料库

资料库用于让助手从你提供的文档中查找依据。内置实现是轻量的本机关键词检索，
无需单独安装向量数据库或配置 Embedding；更完整的语义与图谱检索可使用
[LightRAG 示例](../scenarios/lightrag.zh.md)。

## 1. 开启资料库

在 Gateway 使用的 `config.env` 中设置：

```dotenv
QWEN_AUDIO_DOMAIN_LIBRARY=on
```

按[运行方式](../operations/gateway.zh.md#修改配置后生效)重启 Gateway。
如显式关闭过 `QWEN_AUDIO_KNOWLEDGE_TOOL_ENABLED`，也需恢复为 `true`，
否则资料管理可用但前台没有检索工具。语音 Provider 需要支持工具调用。

## 2. 导入文档

1. 打开已连接该 Gateway 的 **WebUI**，点击顶部“资料库”。
2. 粘贴 **Gateway 所在主机上的文件绝对路径**，例如 `/Users/me/Documents/手册.md`。
3. 点击“加入资料库”，等待导入完成；新文档出现在列表中后再提问。

当前入口不是文件上传器。远程手机上的路径不能指向电脑上的文件；先把文档放到
Gateway 主机。桌面悬浮球与对话面板目前没有资料库管理按钮。

| 文件类型 | 内置实现如何处理 |
| --- | --- |
| Markdown、TXT 等文本 | 直接收录，不要求后台 Agent。 |
| PDF、Word、PPT 等复杂文档 | 由已配置且支持隔离执行的后台 Agent 转成 Markdown；转换能力取决于后台工具环境。 |

复杂文档使用隔离的执行会话，不占用日常协调对话，也不继承语音聊天上下文。
导入失败会在面板提示；没有可用转换器时，可以自行转成 Markdown 或 TXT 后再导入。

## 3. 使用与移除

可以问：“查一下资料库，手册里怎么规定发布流程？”
内置检索按标题和正文关键词返回原文片段，由前台组织回答。
它不是完整的语义检索系统；结果不理想时，尝试文档原词或更明确的问题。

在列表点击“移除”会删除资料库中的文档副本及其检索内容，不会删除原始文件。
聊天附件不会自动收录，资料库也不会自动同步源文件后续修改；更新内容时重新导入。

## 数据与其他知识系统

内置资料库的数据在 Gateway 主机保存。使用云端语音模型时，检索出的片段会作为回答
上下文交给该模型；复杂文档转换也会使用后台配置的模型与工具。导入前确认资料适合这些服务处理。

想复用外部知识库时，参见 [LightRAG 接入示例](../scenarios/lightrag.zh.md)；
开发适配器见 [Knowledge Provider 接口](../reference/knowledge.zh.md)。
