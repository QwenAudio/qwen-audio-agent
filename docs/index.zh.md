## 手册阅读路线

1. [快速开始](./getting-started/quickstart.zh.md)：选桌面版或命令行，完成第一次对话。
2. [基本概念](./getting-started/concepts.zh.md)：了解前台、编排运行时与后台，以及 Gateway 和客户端的作用。
3. [配置语音前台](./configuration/frontend.zh.md)：选云端或本地服务，确认支持的输入与工具。
4. [功能指南](./guides/conversation.zh.md)：使用文字、附件、后台工作和个人数据。

## 常用入口

- [选择后台 Agent](./backends/overview.zh.md)：沿用你的模型、工具与 Skills，也可以先使用仅前台模式。
- [后台工作与授权](./guides/tasks.zh.md)：一边聊天，一边查看进度、补充要求或取消工作。
- [个性化与记忆](./reference/personalization.zh.md)：设置称呼、交流方式与需要长期记住的信息。
- [视觉输入](./guides/vision.zh.md)：区分实时摄像头、聊天附件和按需采集示例。
- [清单与提醒](./guides/notes-reminders.zh.md)：管理条目、到点播报和定时执行。
- [资料库](./guides/knowledge.zh.md)：让回答有自己的文档作为依据。
- [远程连接](./operations/remote-access.zh.md)：从另一台电脑或手机接入 Gateway。
- [故障排查](./operations/troubleshooting.zh.md)：检查连接、音频、后台与工具。
