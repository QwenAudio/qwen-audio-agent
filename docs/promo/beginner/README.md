## 写作原则（本目录所有文案须遵守）

1. **不出现**命令行、npm、API、协议这类词（除非 FAQ 中解释"不需要"）
2. 一切从"下载 → 打开 → 说话"三步出发，技术细节留给 docs/ 正文
3. 涉及云端与本地的边界要诚实：唤醒词本地处理，语音识别/合成经 DashScope 云端
4. 费用表述不写具体数字，引导到官方渠道核实
