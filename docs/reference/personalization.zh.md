# 助手画像与偏好

可以设置助手的默认风格，也可以通过对话保存自己的长期偏好。两者分开保存，升级不会覆盖本地设置。

## 通过对话设置

- “以后叫我船长。”
- “以后回答简洁一些。”
- “我们聊天时，你叫小舟。”

这些明确的长期要求保存为用户偏好。只说“这次简短一点”是临时要求，不应变成长期设置。

## 修改默认助手画像

首次启动会从模板创建 `<config-dir>/ASSISTANT.md`。可用文本编辑器修改名称、人格、关系定位与表达风格，下一次建立语音会话时生效。

也可以指定另一份文件：

```dotenv
QWEN_AUDIO_AGENT_ASSISTANT_PROFILE_PATH=/absolute/path/to/ASSISTANT.md
```

画像不控制声音；音色在[语音前台设置](../configuration/frontend.zh.md)中配置。画像也不能改变工具权限、任务路由或核心运行规则。

## 数据分别放在哪里

| 内容 | 默认文件 | 示例 |
| --- | --- | --- |
| 助手默认画像 | `<config-dir>/ASSISTANT.md` | 默认名称与表达风格 |
| 用户明确的长期偏好 | `<data-dir>/USER.md` | “以后叫我船长” |
| 长期事实与决定 | `<data-dir>/MEMORY.md` | “我住在杭州” |

当前请求优先于长期偏好；用户偏好可以覆盖默认画像。事实记忆帮助理解，不作为权限或执行指令。

对话中的偏好修改立即生效；直接编辑文件后，在下一次语音会话生效。不要在这些文件里保存密码、Key 或验证码。默认路径见[配置与数据目录](../configuration.zh.md#配置与数据目录)。

## 可选偏好学习

默认只保存明确要求。设置 `QWEN_AUDIO_PREFERENCE_LEARNING=on` 后，默认记忆 Provider 还会在会话结束时观察少量特征，跨会话确认后写入 `USER.md` 的“观察推断”段。

此功能默认关闭，会额外调用文本模型。明确要求优先于推断；不需要的推断可在文件中删除。算法与阈值见[偏好学习机制](preference-learning.zh.md)。

## 隐私与其他实现

文件保存在 Gateway 主机，但使用云端模型时，相关画像、偏好和记忆会作为上下文发送给模型。“本地保存”不等于“全程离线”。

自动记忆、查看和删除见[长期记忆](memory.zh.md)。需要替换存储或学习方式时，可使用 [VoiceMem](../scenarios/voicemem.zh.md) 或开发 [Memory Provider](memory-provider.zh.md)。
