# 常见问题（新手版）

## 我完全不懂代码，能用吗？

能。下载 → 安装 → 照着首次启动的设置向导走一遍，就开始说话。**全程不需要敲任何命令**。需要联网注册的东西只有一个：阿里云百炼的账号（用来创建语音服务的 Key），跟着页面点鼠标即可。

## 免费吗？

软件本身**开源免费**（Apache 2.0 许可证），没有任何订阅和付费墙。使用它说话、听话的能力依赖阿里云百炼的语音服务，按官方用量计费（新用户通常有免费额度，以百炼官方页面为准）。

## 我的语音会被上传吗？隐私安全吗？

分两部分，如实说明：

- **唤醒词检测**（说"你好千问"激活）：完全在你的电脑本地运行，音频不出设备
- **语音识别与合成**：经阿里云百炼的语音服务处理（这是它能听懂普通话/英语并开口回答的原因）

你的 Key 和聊天记录只保存在自己电脑的本地目录里，不会上传到我们的任何服务器。

## 支持 Windows / Linux 吗？

桌面悬浮球应用目前只提供 **macOS** 安装包。Windows 和 Linux 用户可以用命令行版本（需要一点终端基础），同样支持语音对话。

## 它和 Siri / 小爱同学有什么区别？

两个最大的不同：

1. **你可以随时插嘴打断**，它像真人一样顺着你的话继续，而不是等它说完才能再下指令
2. **它能真的办事**：挂上 AI 编程助手后，改代码、查资料、跑任务都能用嘴指挥，任务在后台跑，你还能接着聊别的

## 能听懂方言或英语吗？

中英普通话为主；混合对话（中英文夹杂）没问题。方言支持取决于百炼语音服务的能力，会持续改善。

## 会不会误唤醒？

默认不开启唤醒词，需要你在设置里手动打开。开启后它听的是完全本地的小模型，误触率刻意调得保守——宁可少触发一次，也不乱打扰你。

## 小球一直挂在桌面碍事怎么办？

闲置一小会儿它就自动隐身，菜单栏里随时能唤回；也可以直接对它说"可以退下了"让它隐藏。快捷键（默认 `⇧⌘ 空格`）随叫随到。
