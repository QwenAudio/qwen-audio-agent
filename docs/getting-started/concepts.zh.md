# 先了解三个概念

Qwen Audio Agent 将实时对话和后台执行分开：你可以继续聊天，执行进度与结果会回到对话中。

| 组成 | 负责什么 | 在哪里运行 |
| --- | --- | --- |
| 客户端 | 收音、播放、文字与附件输入、显示对话 | 桌面版、浏览器、TUI 或手机 |
| Gateway | 连接模型、管理工具和后台工作、保存状态 | 你的电脑或服务器 |
| 后台 Agent | 使用自己的模型、工具、MCP 和 Skills 办事 | 由 Gateway 启动，或通过适配器接入已有服务 |

**语音前台**是 Gateway 连接的实时模型服务，不是桌面界面。它理解输入、回复用户，并调用可用工具。桌面版内置 Gateway；手机和远程客户端不需要在本机运行后台 Agent。

## 前台模型与后台模型

- **前台模型**负责实时交流，例如 Qwen Audio Realtime。模型能力会影响转写、视觉和工具调用。
- **后台模型**由所选 Agent 使用。默认沿用 Agent 自己的配置；只有显式指定时，Gateway 才请求覆盖。
- 两者的账号、额度和模型配置独立。配置前台 Key 不代表后台已登录。

## 不配置后台也能用

`AGENT_PROTOCOL` 留空或设为 `none` 即为仅前台模式。可以聊天，并使用已启用且语音服务支持的搜索、记忆等工具。需要电脑操作或后台执行的请求则无法完成。

## 会话、工作与工作区

| 名称 | 含义 |
| --- | --- |
| 前台会话 | 一段语音与文字对话；新建会话不清空长期记忆。 |
| 后台工作 | 一次被接受的执行请求，有状态，可以查询或取消；提交成功不等于执行完成。 |
| 后台 Session | Agent 自己维护的执行上下文；是否恢复、如何委派由后台能力决定。 |
| 工作区 | 后台处理项目文件的默认目录，不是权限沙箱。 |

## 本机与远程

默认 CLI 和桌面版可以各自运行 Gateway，共享配置与用户数据，但任务和会话状态独立。要在另一个客户端查看同一实例的工作，必须连接同一 Gateway。

同一 Gateway 中，每个用户只有一个活动客户端。新客户端确认接管后，旧连接会断开，后台工作不会因此被取消。
