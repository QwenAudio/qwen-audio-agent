# 什么场景下你会用到它？

> 犹豫"我用得上吗"的时候，看看这些真实生活片段。

## 🍳 做饭时的帮厨

手上沾满面粉，想知道"红烧肉糖色怎么炒才不糊"——不用洗手擦手掏手机，直接问，它边说边演示步骤，你听一半发现锅里在冒烟，**直接插嘴**"先说怎么救！"，它立刻改口先讲补救办法。

## 🛋️ 瘫在沙发上的晚上

敷着面膜或者抱着猫，不想动手打字："给我讲讲最近有什么值得看的纪录片，别超过三个。" 它用语音回你，觉得第一个不感兴趣，插一句"换一个"，它接着讲下一个——**对话不会因为你打断而生气**。

## 🚶 走路、遛弯、做家务

戴着耳机在屋里走动，让它"把上周说好的健身计划再念一遍"，或者随口问一个突然想到的问题。手在拖地，嘴在提问，两不耽误。

## ⏰ 记性不好也没关系

"提醒我二十分钟后关火"、"提醒我明天早上九点交周报"。时间到了它会**开口提醒你**，而不是弹一个你可能根本没看见的通知。

## 💻 程序员（进阶玩法）

如果你恰好是写代码的：把 Claude Code、Codex 这些工具挂上来，用嘴指挥它改代码、跑任务，重活丢后台慢慢跑，你继续对话；它干完了会自己回来说"改好了"。

## 共同点

这些场景只有一个共同要求：**你的手或眼睛被占用了，但嘴还闲着**。Qwen Audio Agent 就是给这种时刻准备的。
