# 清单与提醒

清单用于记录条目；提醒用于到点通知。二者不等同于后台任务，也不会自动写入长期记忆。

## 管理清单

直接说出清单名称和要做的修改：

- “建一个购物清单，加入牛奶和鸡蛋。”
- “看看购物清单。”
- “从购物清单里删掉鸡蛋。”
- “清空购物清单。”——删除条目，保留清单。
- “删除购物清单。”——删除整个清单。

默认数据保存在 `<data-dir>/frontend-notes.json`，重启后仍保留。没有后台 Agent 也能使用。关闭此工具可设置：

```dotenv
QWEN_AUDIO_NOTES_TOOL_ENABLED=false
```

## 设置提醒

例如：“十分钟后提醒我喝水”或“每个工作日九点提醒我开会”。

当前支持一次、每天、每周和工作日重复。确认回复中应包含触发时间和内容；时间不明确时，请补充日期、时区或具体时刻。

- “提醒我查看报告”只创建到点播报。
- “明早帮我查天气再告诉我”要求到点执行，需要配置后台 Agent。
- 可以询问已设提醒，或明确要求取消某个提醒；重复提醒请说明是否取消整个系列。

关闭提醒工具：

```dotenv
QWEN_AUDIO_SCHEDULE_TOOL_ENABLED=false
```

## 运行条件

提醒由创建它的 Gateway 管理。需要准时触发时，保持该 Gateway 运行、主机不休眠，并让可播报的客户端保持连接。

提醒记录会持久化。Gateway 重启后会处理仍在等待的过期提醒，但这不等于系统级闹钟或手机推送服务，不能保证离线时准点通知。桌面隐藏期间不会强制唤醒播报。

这些功能依赖语音前台支持工具调用；MiniCPM-o 当前适配不支持。Gateway 常驻方式见[运行与常驻](../operations/gateway.zh.md)。
