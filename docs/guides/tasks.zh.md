# 后台工作与授权

配置好[后台 Agent](../backends/overview.zh.md)后，可以直接要求助手查询电脑信息、修改文件、
编写程序或使用后台已有的工具与 Skills。执行能力、登录状态和可操作范围由后台环境决定。

未配置后台时，前台不提供 `spawn_thinking` 或 `update_agent_task`，也不能创建定时执行任务；
聊天、可用的前台工具以及定时提醒仍可使用。工作查询和取消工具保留，用于管理提醒等已有记录。

## 发起与继续

- 发起工作：“帮我做一个极简的网页小游戏。”
- 补充要求：“刚才那个页面改成深色背景。”
- 查询：“现在进行到哪里了？”
- 取消：“取消刚才那个小游戏。”

后台工作异步进行，不会要求你停止聊天。继续某项工作时，说明目标或引用卡片中的标识，
尤其在同时有多项工作时。是否支持恢复原生会话、独立工作或特定工具，取决于所选后台；
不能把某个后台的能力当作所有后台的保证。

运行时默认一次执行一项用户工作，后续工作排队；新增工作不会隐式取消已有工作。
等待输入、权限或处于委派阶段的工作仍占用槽位，直到整项任务结束。
仍可回答该任务的追问或调整当前工作，不必新建任务。默认配置为
`QWEN_AUDIO_AGENT_TASK_MAX_CONCURRENT_PER_OWNER=1` 和 `QWEN_AUDIO_AGENT_TASK_MAX_CONCURRENT=1`，
两个上限仍可显式配置。ACP 默认只有一个协调槽位，调整或续接时使用任务记录的原上下文。
Session 不隔离文件、工作目录或外部资源。

### 调整正在执行的工作

“再画一只小猫”是排队新增工作，不会取消正在绘制的小狗；“把刚才的小狗改成小猫”才是调整。
前台用 `spawn_thinking` 新建，用 `update_agent_task` 定向补充、修改或回答追问，沿用同一个工作 ID 和原后台上下文。
指代不清时先确认目标，而不是按“后台是否忙碌”猜测。

- 排队中：把新要求合入该工作的首次执行，不影响正在执行的其他工作。
- 等待输入：用 `instruction` 把用户答复交回同一任务，可用 `input_request_id` 绑定具体请求。
  确认、拒绝或修改条件都保留用户的自然语言，由后台结合原上下文解释；修改条件不代表批准旧预览。
- 执行中：ACP 后台优先使用已确认支持的注入扩展；否则取消当前轮次，等待结束后在同一会话续接。
- 已完成：原上下文可用时可以继续，仍使用原工作 ID；原来的结果保留在历史中。
  原会话正被其他任务占用时等待该会话空闲，不能把调整发给其他任务。

调整受理不等于已生效，也不会撤销已经执行的操作。改变工作要求时，按任务授予的权限会重新确认，
会话内“始终允许”保持有效。后台不支持调整、会话不可恢复或结果仍在投递时，会返回明确错误。
原生后台自己创建的委托、已结束的委托工作暂不支持自动续接；运行中的框架 ACP 委托支持定向调整。
网关重启后不会自动重发未确认投递的要求，避免重复执行。终止整项工作使用 `cancel_agent_task`，
后台权限决定仍使用 `respond_permission`。

## 看懂工作状态

提交成功表示已接受请求，不表示工作完成。卡片可以显示排队、执行中、等待输入或授权、
准备播报以及最终结果。查询和取消也应以实际返回的状态为准；提出“取消”不等于已经停止。

后台可能需要追问，而不是交付最终结果。此时回答它的问题即可继续。
工作失败时保留错误信息，检查后台登录、模型额度和工具环境，不要仅凭前台连接正常判断后台可用。

## 允许与拒绝

后台提出真实权限请求时，界面显示待确认操作，前台可向你询问。可以自然表达：

| 决定 | 效果 |
| --- | --- |
| 允许此任务 | 允许当前任务及其后续操作，直到任务完成、失败或取消；其他任务需重新授权。 |
| 始终允许 | 在当前前台会话内允许后续由 Gateway 管理的权限请求，不是永久修改所有后台配置。 |
| 拒绝 | 拒绝当前请求。 |

普通同意按“允许此任务”处理，后续操作（包括写入或删除）也在此授权范围内。
授权只保存在当前 Gateway 进程中，重启后需重新确认。

多项工作同时等待授权时，说明你允许或拒绝哪一项。并非所有后台都会提供权限事件；
例如不具备审批能力的后台，不能靠前台凭空增加沙箱。后台原生安全限制也不一定能由
Gateway 的“始终允许”解除。

`native` / `full` 启动权限模式与后台差异见[后台权限模式](../configuration/backend.zh.md#后台权限模式)。

前台 MCP / OpenAPI 工具的确认和鉴权由对应服务负责，不要把后台审批流程当作所有工具的统一保护。
配置工具时只启用你信任且确实需要的操作。
